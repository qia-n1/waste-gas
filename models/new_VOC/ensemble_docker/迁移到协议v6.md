# 从 ensemble_docker 迁移到固定 v6 协议

本目录原先用于 DLinear PCA 集成服务（端口 8000）。
当前迁移目标是切换到固定 v6 协议服务，对齐 模型端后端交互协议_v6.md。

## 1. 新增迁移文件

- Dockerfile.v6: 构建固定 v6 服务镜像。
- docker-compose.v6.yml: 固定 v6 部署编排。
- .env.v6.example: v6 环境变量模板。
- verify_v6_contract.sh: 协议关键字段与门禁校验脚本。

## 2. 迁移步骤

1. 复制环境变量模板。

   cp .env.v6.example .env.v6

2. 检查模型工件存在。

   - ../../../models/vocs_seq2seq_v6_best.pth
   - ../../../models/vocs_scalers_v6.pkl

3. 启动 v6 服务。

   docker compose --env-file .env.v6 -f docker-compose.v6.yml up --build -d

4. 校验服务状态。

   curl http://127.0.0.1:8001/status

   需要满足：
   - module_ready=true
   - model_family=v6
   - inference_contract_version=v1-fixed-v6

5. 运行协议校验脚本。

   chmod +x verify_v6_contract.sh
   ./verify_v6_contract.sh http://127.0.0.1:8001

## 3. 与旧服务差异

- 端口从 8000 切换为 8001。
- 模型与 scaler 必须是 v6 工件，未就绪时 /predict 返回 503。
- /predict 请求固定为 96 步，每步 feature_values 固定 25 维。
- 返回体要求包含 incremental_attribution.heatmap，且矩阵维度固定为 24x3。

## 4. 对接建议

- 后端优先走 POST /predict（主链路）。
- POST /sensor-data 作为兼容链路保留。
- 上线前把 /status 检查纳入启动探针或发布门禁。
